# leo-legal

Public privacy and terms-of-use pages for **Leo**, a private notification bot used only by Phillip Collins.

## What is here

| File | Purpose |
|---|---|
| `privacy.html` | Privacy statement for Leo |
| `terms.html` | Terms of use for Leo |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are, without a Jekyll build |

## Why this repository is public

The Microsoft Teams app that Leo uses asks for links to a privacy statement and terms of use, and those links must open on the public web. This repository holds only those two statements.

## Rules for this repository

- No passwords, keys, tokens, identifiers or details of my systems belong here.
- If what Leo does changes, update both pages and their "Last updated" dates.
